Details relating to model domains:
Covariance-based 2-sigma uncertainties are used as guideline model domain limits. Each input channel's 1-sigma uncertainties are contained within the associated CSV files.

Limits are stored in energy group format using the covariance energy structure, with each bin having a lower bound in column 'E_low_eV' and the upper limit in 'E_high_eV'. Units are all in eV. The 1-sigma uncertainty is given in % format, and for the recommended 2-sigma limit this simply needs to be multiplied by 2 in each case.
